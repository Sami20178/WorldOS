# World OS

World OS is a cross-platform operating system project designed for desktop, mobile and tablet experiences.

## Platforms
- Desktop
- Mobile
- Tablet

## Project structure
- `core/` shared operating-system logic
- `desktop/` desktop interface
- `mobile/` mobile/tablet interface
- `shared/` shared configuration and theme
- `apps/` built-in applications
- `docs/` documentation

## Current version
0.1.0 — World OS UI prototype
